## 文件组织

每个案例包含：

- `G_金标准_*.md`：脱敏后的专家定稿 Markdown；
- `I_降质版_*.md`：按对应 defects 清单植入缺陷后的练习输入；
- `O_参考磨课输出_*.md`：模拟“良好但不完美”的磨课输出；
- `defects_*.json`：G→I 的缺陷记录，供评审校准与差分核对。
