# 如果山水会说话——我是家乡山水推荐官

设计团队：某教育研究团队（信息已按合作协议脱敏）

本单元对应《义务教育语文课程标准（2022年版）》。

## 学情分析

本单元面向八年级学生。前测数据显示：约65%的学生能初步识别借景抒情手法，但仅30%能结合背景分析情感；约70%的学生对文言散文存在畏难情绪，阅读速度偏慢。据此调整：为阅读薄弱学生提供《小石潭记》白话对照版；任务2的三选一选项按难度分层（A实地考察为高挑战，B采访搜集为中挑战，C资料研读为基础挑战）；写作要求保留600字但允许选择书信体等较易上手的形式。

## 教学重难点

**教学重点**：从多角度梳理景物描写，理解借景抒情、情景交融的写作手法，并能迁移运用。
**教学难点**：将经典散文中的手法灵活迁移至自己的观察与写作中，实现“景中有情、情中有景”。

## 单元简介

山水不仅是自然景观，更是中国人精神世界的寄托。从“会当凌绝顶，一览众山小”的豪迈，到“采菊东篱下，悠然见南山”的恬淡，古人用文字为山水赋予了生命与情感。本单元以“如果山水会说话”为核心议题，学生将以“家乡山水推荐官”的身份，学习借景抒情、情景交融的写作手法，最终完成一篇为家乡山水代言的推介文章。

## 单元目标

1. **【语言运用·审美创造】** 能运用语言文字，从视觉、听觉、触觉、动静、虚实等角度梳理《小石潭记》《醉翁亭记》（节选）中的景物描写，并结合背景资料推断作者情感，体现审美创造素养。
2. **【语言运用·思维能力】** 能分析文本中景物特征与情感表达之间的关联，运用借景抒情、情景交融的写作手法，并能口头或书面阐释这种关联，体现思维能力素养。
3. **【语言运用·审美创造】** 能通过实地观察或资料搜集，选定家乡的一处山水景点，运用所学手法完成一篇不少于600字的推介散文，做到“景中有情、情中有景”，体现语言运用与审美创造素养。
4. **【文化自信·语言运用】** 能在小组中分享并互评作品，从“景物描写是否生动、情感表达是否自然、语言是否优美、创意构思是否新颖”四个维度给出具体建议，并在交流中增强对家乡山水文化的认同，体现文化自信与语言运用素养。

## 项目导引：当山水有了声音

### 【项目背景】

你听说过“蚌埠住了”“洛阳纸贵”这些和地名有关的梗吗？如果家乡的山水会说话，它们会向我们诉说什么？

每一座山、每一条河，都有它独特的故事——可能是地质变迁的亿万年纪事，可能是文人墨客留下的千古诗篇，也可能是祖辈口口相传的民间传说。而今天，这些故事需要你来讲述。

### 【开启项目】

你们将担任“家乡山水推荐官”，为学校文化节制作一份“家乡山水名片”。优秀作品将入选校刊《故乡的山水》专栏，并推荐至区级征文比赛。成为推荐官，你不仅会学会如何让山水“说话”，更会在观察与写作中重新发现家乡的美，成为家乡文化的传承者。

### 【驱动性问题】

**如果家乡的山水会说话，它们会向我们诉说什么？** 这个问题将贯穿三个任务：任务1从经典散文中学习山水如何“说话”，任务2观察家乡山水寻找“说话”的素材，任务3为家乡山水代言，让它们“说”出独特的故事。

### 【任务1：品读·悟法——学习景中藏情之法】（建议用时：2课时）

#### 经典研读：《小石潭记》·柳宗元

从小丘西行百二十步，隔篁竹，闻水声，如鸣珮环，心乐之……潭中鱼可百许头，皆若空游无所依。日光下澈，影布石上，佁然不动；俶尔远逝，往来翕忽，似与游者相乐……坐潭上，四面竹树环合，寂寥无人，凄神寒骨，悄怆幽邃。以其境过清，不可久居，乃记之而去。

**【交流研讨】**（教师活动：教师负责追问引导，如“从‘心乐之’到‘凄神寒骨’中间发生了什么？”）

1. 柳宗元笔下的水声是怎样的？心情如何？——心情变化：心乐之 → 似与游者相乐 → 凄神寒骨
   - **你的依据是什么？**（预设：学生能答出“由乐到凄”变化链；典型误区：忽略“寂寥无人”的环境触发）
2. 同一条小石潭，为什么心情会发生这样的变化？景物描写与作者命运有什么关系？
   - **你的依据是什么？**（预设：学生能答出“被贬经历影响心境”；典型误区：脱离文本空谈背景）
3. 文中的鱼是“实写”还是“虚写”？“似与游者相乐”用了什么修辞手法？
   - **你的依据是什么？**（预设：学生能答出“虚实结合”和“拟人”；典型误区：将“似与游者相乐”误答为比喻，或认为鱼完全虚写）

**【推荐官手账任务】**：作为推荐官，你需要从《小石潭记》中提取至少三种描写手法，填入你的“推荐官手账”，并说明这些手法可以如何用于介绍家乡的某处山水。

**【完整分析示例】**（在学生自主研讨后，教师出示此示例作为验证与补充。示例只填第一行，后两行留白，供学生尝试填写后对照。）

| 景物描写 | 感官角度 | 景物特点 | 作者情感 | 推断依据 |
|---------|---------|---------|---------|---------|
| “隔篁竹，闻水声，如鸣珮环” | 听觉 | 清脆悦耳 | 心乐之（愉悦） | 正面描写水声之美，直接点明心情 |
| “潭中鱼可百许头，皆若空游无所依” | 视觉 | 清澈灵动 | 似与游者相乐（闲适） | 以鱼之乐写人之乐，暗示作者此刻的闲适心境 |
| “四面竹树环合，寂寥无人” | 视觉 | 清幽冷寂 | 凄神寒骨（孤寂） | 环境触发心境变化，由乐转凄 |

---

#### 经典研读：《醉翁亭记》（节选）·欧阳修

若夫日出而林霏开，云归而岩穴暝，晦明变化者，山间之朝暮也。野芳发而幽香，佳木秀而繁阴，风霜高洁，水落而石出者，山间之四时也。朝而往，暮而归，四时之景不同，而乐亦无穷也。

**【交流研讨】**（教师活动：教师负责追问引导，如“从‘朝而往，暮而归’到‘乐亦无穷’，欧阳修的快乐来自哪些层次？”）

1. 作者写出了琅琊山哪些时间段的景色？用表格整理。
   - **你的依据是什么？**（预设：学生能答出“朝暮、四时”；典型误区：遗漏“晦明变化”）
2. “乐亦无穷”中的“乐”包含了哪些情感？与柳宗元的“凄神寒骨”对比，有什么不同？
   - **你的依据是什么？**（预设：学生能答出“山水之乐、宴饮之乐、与民同乐”；典型误区：简单归为“开心”）

| 文本 | 景物特点 | 作者心境 | 背景关联 |
|------|---------|---------|---------|
| 《小石潭记》 | 清幽冷寂 | 凄苦孤寂 | 被贬永州 |
| 《醉翁亭记》 | 朝暮四时各异 | 乐亦无穷 | 被贬滁州 |

**【推荐官工具箱】**：请从经典散文中提取可迁移的描写方法，口头表达并记录在手账中。（教师活动：组织学生提炼方法，如“多角度观察”“虚实结合”“情景交融”。教师汇总学生口头表达的方法，板书归类，针对“只列手法名称未说明迁移方式”的典型问题组织全班讨论补充。）

**【任务反思】**：回顾推荐官手账，用一句话概括今天学到的最有用的描写手法。

**【衔接段】**：从经典散文学到的借景抒情方法将用于任务2的观察记录。请在观察记录表中同步标注你借用了任务1中的哪种手法。

### 【任务2：观察·选材——选择你的描写对象】（建议用时：1课时+课后）

走出教室，用双脚丈量家乡的土地，用眼睛寻找那些值得被讲述的山水。（教师活动：教师提前踩点并准备安全预案，巡视时用追问引导学生从多角度观察）

**任务选项**（三选一，按难度分层）：
- A. 实地考察（高挑战）：前往一处本地景点，实地观察并记录。**安全提示：实地考察需结伴而行，提前告知家长去向与返回时间，远离水域陡坡等危险区域，注意交通与天气安全。**
- B. 采访搜集（中挑战）：采访长辈，搜集某处山水的老故事
- C. 资料研读（基础挑战）：通过地方志或网络资源深度研究一处山水

| 触觉/嗅觉 | | | |

**预设与应对**：学生可能只填写“具体内容”列而忽略“可引发的联想/情感”列和“对应手法”列→教师巡视时追问“看到这个颜色让你想到什么心情？”“这个观察角度可以用《小石潭记》中的哪种手法来写？”

**【任务反思】**：对照观察记录表，检查哪个维度的素材还不够，思考如何补充。

**【衔接段】**：观察记录表中的素材是任务3创意写作的直接来源。

### 【任务3：写作·代言——创意写作】（建议用时：2课时+成果发布会1课时）

**写作要求**：
- 自选家乡一处山水（可以是名山大川，也可以是小河土坡）
- 运用借景抒情的手法，写出景物的独特之处
- 可尝试创新形式：书信体（给山水的一封信）、拟人化（山水自述）、时空对话（与古人共游）等
- 字数不少于600字
- （教师活动：教师提供写作提纲模板并组织当堂片段试写）

**预设与应对**：学生可能不知如何开头→教师引导参考下方写作提纲模板中的“设问/引用”开头示例。

#### 【成果发布会】（教师活动：组织互评分享）

1. **组内轮读**：小组内轮流朗读作品。
2. **填写互评量规**：使用下方“问题解决成果量规”进行同伴互评。
3. **口头反馈**：从“景物描写是否生动、情感表达是否自然、语言是否优美、创意构思是否新颖”四个维度给出具体建议。
4. **写法对比**：教师选取2—3篇写法差异明显的作品（如书信体 vs 拟人化），组织全班讨论“不同形式对情感表达的效果有何不同”，引导学生从差异中生成新认识。
5. **修改**：根据反馈修改作品。
6. **班级展示**：每组推荐1份优秀作品进行班级展示，优秀作品将入选校刊《故乡的山水》专栏，并推荐至区级征文比赛。
