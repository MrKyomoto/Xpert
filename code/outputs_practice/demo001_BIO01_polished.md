# 共建清新校园——防治校园飞絮

设计团队：某教育研究团队（信息已按合作协议脱敏）

## 项目简介

每年春夏之交，校园里的杨树和柳树开始飘絮，漫天飞舞的白色绒毛不仅影响校园环境，也给过敏体质的师生带来困扰。这些飞絮究竟是什么？为什么会“爆发式”飘散？有没有科学有效的防控方法？本项目以“共建清新校园”为真实情境，学生以“校园环境问题研究员”的身份，通过生物学探究、实地调查和社会实践，系统研究校园飞絮问题的成因与对策，最终形成一份可实施的《校园飞絮防治建议方案》，提交给学校管理部门。

## 学情分析

- **已有认知**：学生对飞絮现象有直观感受（常见于春季），部分学生可能知道飞絮来自杨树和柳树，但对飞絮的生物学本质（种子传播结构）缺乏准确认识，容易混淆“花”与“种子”。
- **先备知识**：学生已学习植物六大器官（根、茎、叶、花、果实、种子）的基本概念，具备初步的观察和记录能力，但数据记录与图表阅读能力参差不齐，合作学习经验有限。
- **迷思概念**：常见误解包括“飞絮是花”“飞絮是花粉”“飞絮是雄株产生的”等。
- **支架设计依据**：基于上述学情，难点1（结构功能推理）需提供对照图模板降低认知负荷；难点2（权重设定）需提供评分卡简化决策过程。**（注：若已有官方学情profile文档，请附入本轮审查范围，以进一步核对支架适配性。）**

## 驱动性问题

我们能否用科学方法查明校园飞絮的根源，并提出一套既有效又可行的防治方案？

## 项目目标

1. 能通过解剖观察杨树和柳树的雌雄花序，说出飞絮是雌株的种子及其绒毛结构，解释飞絮与风力传播种子的关系，初步建立结构与功能相适应的生命观念。

2. 能通过实地调查与数据分析，绘制校园飞絮分布热力图，探究飞絮发生的环境条件（温度、湿度、风力等），培养探究实践与科学思维能力。

3. 能通过查阅文献和访谈，对比不同防治方案（修剪、喷水、药剂抑制、树种替换等），从科学性、经济性、可行性等维度进行综合评价，能基于证据做出决策并说明理由。

4. 能以小组合作形式撰写一份《校园飞絮防治建议方案》，并做3分钟口头汇报，在回应提问中体现社会责任感与公共表达能力。

## 教学难点

- **难点1**：从生物学结构证据推理飞絮功能（如将雌花序的绒毛结构与风力传播种子建立联系）。  
  **支架**：提供“结构—功能”对照图模板，引导学生标注观察到的结构并推测其功能。  
  **使用示例**：模板左侧画雌花序示意图（标注绒毛、种子），右侧留空写“功能推测”，教师示范：“绒毛轻而多，推测有利于被风吹到远处；种子小，推测可随绒毛飘散。”学生仿照完成。

- **难点2**：多准则决策中权重设定的依据（如为何经济性比可行性更重要？）。  
  **支架**：提供AHP简易评分卡，引导学生先小组讨论确定各准则权重，再计算综合得分。  
  **使用示例**：评分卡包含“科学性、经济性、可行性”三列，学生先两两比较重要性（如科学性比经济性重要则记2分，同等记1分），归一化后得权重，再乘以各方案得分求和。

## 项目导引：飞絮的困扰

### 【项目背景】

“春天来了，又到了杨絮柳絮飘飞的季节。”每年4-5月，校园里就像下起了“雪”。对此，同学们的感受不一：有的觉得“像童话一样浪漫”，有的则苦不堪言——打喷嚏、流眼泪、皮肤发痒，甚至影响户外活动。学校后勤部门每年投入大量人力清理飞絮，但收效甚微。

---

**【调查分析】** 飞絮到底是什么？为什么今年飘絮特别多？有没有办法从根源上解决问题？

---

### 【开启项目】

现在你们就是“校园环境问题研究员”，学校委托你们组建研究团队，用4周时间完成一项任务：查明飞絮的生物学根源，提出科学可行的防治方案，并向学校提交正式报告。优秀方案将纳入学校年度环境治理计划。

---

### 【活动一：飞絮的生物学探查】

#### 1.1 实地观察与环境数据采集

选择校园内飞絮最严重的3个区域，观察并记录：

| 地点 | 树种种名 | 树龄（估） | 飞絮数量级 | 天气条件（温度/湿度/风力） |
|------|---------|-----------|-----------|-------------------------|
|      |         |           |           |                         |

**环境数据采集**：使用温湿度计/风速仪，在3个区域分别记录温度、湿度、风力数据（建议每个区域记录3次取平均值）。小组汇总数据后，在校园平面图上标注各区域飞絮数量级与环境数据，初步绘制飞絮分布热力图草图。

#### 1.2 结构探究

**安全提示**：
- 对杨絮柳絮过敏的同学请佩戴口罩、手套操作。
- 使用解剖针/剪刀时注意安全，避免划伤。
- 废弃植物材料统一收集处理，不得随意丢弃。

采集杨树/柳树的雄花序和雌花序，完成解剖观察：

- 雄花序：观察花药结构，是否有大量花粉？
- 雌花序：观察柱头形态，寻找种子和绒毛的连接方式
- 对比结论：飞絮是______（填雄/雌）株的______结构（答案：雌株的种子及其绒毛）

**【交流研讨】**

- **问题1**：为什么杨树和柳树要产生这么多绒毛？这对其繁殖有什么意义？  
  **元认知追问**：你的推断依据了哪些观察证据？请说明你的推理过程。  
  **预期回答示例**：绒毛轻而多，有利于种子被风吹到更远的地方，扩大分布范围。  
  **常见误解**：误认为绒毛是花的一部分，或认为绒毛是为了吸引动物传播。  
  **教师追问/纠正**：引导学生对比雄花序（有花粉）和雌花序（有绒毛+种子），指出绒毛直接连接种子，是种子传播的适应结构。

- **问题2**：为什么飞絮常在短期内集中爆发？  
  **元认知追问**：你推测的触发因素是什么？有没有观察或数据支持你的想法？  
  **预期回答示例**：可能与温度升高、湿度降低有关，种子成熟后同时释放。  
  **常见误解**：认为是风把其他地方飞絮吹来的。  
  **教师追问/纠正**：引导学生结合环境数据（温度、湿度）分析，指出种子成熟的时间窗口。

- **问题3**：校园里只有杨树和柳树吗？为什么其他树（如樟树、桂花树）不产生飞絮？  
  **元认知追问**：请比较这些树的果实或种子结构，你的结论是什么？  
  **预期回答示例**：樟树、桂花树的果实是核果或浆果，靠动物或自身重力传播，不需要绒毛。  
  **常见误解**：认为所有树都会产生飞絮。  
  **教师追问/纠正**：展示不同果实类型图片，引导学生归纳种子传播方式与结构的关系。

**教师使用说明**：教师将各组推理要点记录于白板，在活动二方案比较时引导学生回顾自己的推理，检验推理是否支持方案选择（如“你们之前认为飞絮是种子传播结构，那么修剪枝条能否阻止种子形成？”）。

### 【活动三：研究成果汇报】

#### 3.1 完整汇报流程
