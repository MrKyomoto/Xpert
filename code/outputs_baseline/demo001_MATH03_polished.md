**【方法导引】如何对数据进行分析**

-   **Step1. 数据清洗：** 去除异常值、重复值和缺失值，确保数据准确性。
-   **Step2. 初步分析（定性）：** 找出数据之间的变化趋势和大致规律。
-   **Step3. 进一步分析（可视化）：** 将数据以图表形式展示，更直观地观察关系。
-   **Step4. 结果解释：** 根据分析结果，阐述实验目的是否达到，关系是否符合预期。

在现实世界中，这样的正比关系还有很多，比如：单价一定时，总价与质量成正比；速度一定时，路程与时间成正比。
